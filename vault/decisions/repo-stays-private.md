# The repo stays private until submission

`github.com/AmitChowdary122/zcring` is **private**, and stays that way until
the Stage 1 form needs the public link.

Reasoning: the submission form requires a public GitHub link, so it must go
public eventually. But public-early is an unnecessary plagiarism risk in a
competition where originality is a stated rule
([[decisions/problem-statement]]) and other entrants are working the same
problem statement.

**Flipping it to public is a submission-day step**, and it is on
[[submission/stage1-checklist]]. Do not forget it — a private link on the form
is a wasted submission.

## Consequence I keep hitting

My sandbox has no GitHub credentials, so I cannot fetch or clone it. See
[[traps/i-cannot-fetch]]. This is not fixed by making the repo public; it is a
property of my environment.
